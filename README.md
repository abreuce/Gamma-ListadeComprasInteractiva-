# 🛒 SmartShop - Aplicación de lista de compras interactiva

**Proyecto de Estructuras de Datos**

## Descripción del Proyecto
SmartShop es una aplicación en C++ que permite gestionar una lista de compras de forma dinámica. El objetivo es implementar todas las estructuras de datos vistas en clase (pilas, colas, listas enlazadas, árboles, grafos, hashing, etc.) aplicadas a un caso real.
