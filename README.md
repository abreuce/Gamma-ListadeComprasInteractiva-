# SmartShop: Aplicación de Lista de Compras Interactiva

## Proyecto de Estructuras de Datos

### Descripción

SmartShop es una aplicación desarrollada en C++ como proyecto académico para la asignatura Estructuras de Datos. Su propósito es demostrar la implementación y el uso de diferentes estructuras de datos mediante la simulación de un sistema de gestión de inventario y lista de compras.

El proyecto fue desarrollado aplicando estructuras de datos implementadas desde cero y otras apoyadas en la Biblioteca Estándar de C++ cuando fue apropiado, con el objetivo de reforzar los conceptos vistos durante el curso.

## Estructuras de Datos Implementadas

El proyecto incluye las siguientes estructuras de datos:

- ✅ Pila (Stack)
- ✅ Cola (Queue)
- ✅ Lista Enlazada Simple
- ✅ Tabla Hash
- ✅ Grafo (Matriz de Adyacencia con recorrido DFS)

Las estructuras no implementadas se encuentran justificadas en el archivo **JUSTIFICACION.md**.
